# 🎯 Academia de Tiro

Aprende a programar desde cero disparando. Cinco lecciones interactivas, estilo Duolingo o Codecademy, que enseñan conceptos básicos de programación con mecánicas de juegos de disparos: munición, recarga, ráfagas, daño e inventario.

Pensado para niños y adolescentes. En cada lección el alumno lee una explicación corta, edita una línea de código y ve el resultado al instante en un minijuego.

## Lecciones

| # | Concepto | Misión |
|---|----------|--------|
| 1 | **Variables** | Agranda la capacidad del cargador para destruir todos los objetivos sin recargar. |
| 2 | **Condicionales** | Arregla el `if` para que la torreta recargue solo cuando se queda sin balas. |
| 3 | **Bucles** | Usa un `for` para disparar ráfagas y derribar enemigos blindados. |
| 4 | **Funciones** | Completa el `return` de una función de daño y derrota al jefe. |
| 5 | **Arrays** + examen final | Arma el inventario de armas y responde 5 preguntas sobre todo lo aprendido. |
